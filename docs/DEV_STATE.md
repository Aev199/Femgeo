## Принятые решения и допущения

- Расчёты сечений — перенос на Rust, а не вызов .NET (скорость, один exe);
  обновления автора — `upstream/opencs.lock`, `scripts/upstream_diff.sh`.
- Ошибка в CSfea `Shell4.BMatrixShear` (транспонированный Якобиан, на
  искажённой сетке прогиб −46 %) исправлена у нас; **автору не сообщать**
  (решение пользователя).
- СП 24: ν в ζ0, mν (табл. 7.18) — (ν1 + ν2)/2; отступ сваи от края ростверка
  в норме числом не задан — 0,5d + 0,1 м, параметр.
- СП 63: таблицы сверены (А400 по Изменению № 1: 340/340/390 МПа); Rsc А500 =
  400 МПа (кратковременное действие); деформации бетона — как в OpenCS.
- Трещины (п. 8.2.6): продолжительное — длительное сочетание, φ1 = 1,4, 0,3 мм;
  непродолжительное — полные сочетания с φ1 = 1,4, 0,4 мм (верхняя оценка
  acrc1 + acrc2 − acrc3). Подбор ПС2 — только где сетки ПС1 не проходят.
- Продавливание — пп. 8.1.46–8.1.47 без поперечной арматуры; у края — доля
  контура внутри плиты (упрощение двух вариантов контура).
- Загружения хранятся нормативными; признак «расчётные» — деление на γf.
- Вудбери: регуляризующие пружины плиты 1e-6 жёсткости сваи (берут ~1e-5
  нагрузки). Конденсированный суперэлемент для больших зданий неэффективен —
  для них полная модель «здание + плита» в K0.
- Сетка плиты в окне — квадратная по габариту (косые края ступенькой); сваи —
  в узлах сетки.

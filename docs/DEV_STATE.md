## Этапы

Критерий приёмки этапа фиксируется **до** прогона на реальных данных и не
ослабляется под результат.

### Этап 1. Расчёты сечений по СП 63 (перенос CScore)

- Каркас крейта, типы усилий и единиц, статусы `ok / fail / indeterminate`.
- Подбор сеток плит по Капра–Мори, ПС1 и ПС2; поперечная сила в плитах.
- НДМ круглого сечения сваи.

Приёмка:
- перенесённые тесты CScore (`CScore.Tests/ShellSimpl*`, круглые сечения)
  проходят с теми же допусками;
- на выгрузке усилий плит ЛИРА (реальный объект, не коммитится) поля As
  сравниваются с армированием ЛИРА; метрики расхождения и порог фиксируются
  до первого прогона;
- сваи: совпадение с эталонами АРБАТ из `cscore-pile-poc` в его допусках.

### Этап 2. Линейный решатель

- Оболочки (MITC4, перенос из CSfea), стержни, пружины, жёсткие связи.
- Разреженный решатель (`faer`), загружения, сочетания СП 20, РСУ.
- Конденсация здания на узлы плиты (суперэлемент).
- Чтение модели из `topo_reconstruct_rs`, толщина плиты из модели.

Приёмка: patch-тесты; аналитические эталоны (плита Навье, консоль);
на модели ЛИРА с теми же коэффициентами постели перемещения и усилия
совпадают с ЛИРА в зафиксированных допусках; конденсированная и полная
модели дают одинаковый результат на плите.

### Этап 3. Модель свайного поля

- Чтение geobase (`*.db`, только чтение) и поверхностей слоёв.
- Жёсткость и взаимовлияние свай по СП 24, раздел 7.4.
- Сваи, встроенные в сетку плиты через функции формы.
- Конструктивные правила СП 24 с номерами пунктов; допустимый контур.

Приёмка: ручной пример по СП 24 для одиночной сваи и пары свай;
инвариантность к порядку, переносу и повороту; перемещение сваи внутри
элемента плиты не даёт скачков результата.

### Этап 4. Оптимизатор расстановки свай

- Начальная расстановка по правилам, итеративное улучшение, несколько
  стартов.
- Фронт «число свай — кг/м³», средний уровень точности для лучших вариантов.
- Выход: DXF/CSV плана, таблица свай, осадки, поля армирования, отчёт.

Приёмка: на синтетических случаях с известным решением (симметричная плита,
равномерная нагрузка) результат симметричен и не хуже ручной расстановки;
все варианты фронта проходят все ограничения; детерминизм при фиксированном
seed.

### Этап 5. 3D-грунт и гибридная схема

- Генерация 3D-модели «здание + грунт» (Gmsh), запуск Code_Aster, чтение
  результатов.
- Гибрид сочетаний (`SPEC.md`, §4.1).
- Проверка финалистов оптимизации.

## Блокеры и открытые вопросы

- Перечень конструктивных требований СП 24 с номерами пунктов — этап 3.

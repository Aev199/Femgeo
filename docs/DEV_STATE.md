# Состояние разработки

Обновлено: 2026-11-01. Постановка — `docs/SPEC.md`.

Схема: topo_reconstruct_rs (вход, доводка геометрии, сетка, нагрузки, окно)
→ `femgeo::building::split` (плита + здание + сваи КЭ 56) → `optimize::Problem`
(подбор) → результаты обратно в окно topo. Ветка работы —
`stage1-sp63-plates` (в `main` не влита; `main` содержит только постановку).

## Что готово

| Модуль | Содержание | Проверка |
|---|---|---|
| `src/sp63` | Перенос OpenCS/CScore (`387e157`): диаграммы L2/L3, НДМ полосы, ПС1, трещины, подбор и проверка Капра–Мори ПС1/ПС2, поперечная сила плит, фибровое сечение и предельный множитель сваи, случайный эксцентриситет | Тесты CScore, эталоны OpenCS (Кисп изгиба 0,496; γ 1,724), АРБАТ по сваям ≤ 0,87 %, побитовый отпечаток |
| `src/fem` | Оболочки MITC4/T3 (перенос CSfea с исправлением, см. ниже), стержни, пружины, группа пружин, суперэлемент, `faer`; конденсация здания на плиту | Навье, консоль, искажённая сетка, патч-тест, поворот в 3D; конденсация = полная модель до 1e-8 |
| `src/piles` | Осадка и взаимовлияние по СП 24.13330.2021 (7.33–7.41, табл. 7.18), матрица поля; правила расстановки (п. 8.13), область с отверстиями | Формулы по шагам, длинные и короткие сваи, инвариантность |

| `src/loads.rs` | Сочетания СП 20, п. 6.4 (основные): ПС1, ПС2, длительное ПС2 | Коэффициенты, Σ реакций = определяющее сочетание |
| `src/optimize` | Подбор свай: режимы «рядами» (снятие рядов и зеркальных пар, предпочтение симметрии) и «свободно» (перенос свай, ориентир — существующие сваи); фронт «число свай — кг/м³»; ограничения: Fd, материал сваи, продавливание, s, Δs/L, подбор армирования ПС1/ПС2 | Равновесие, правила, Вудбери = прямой расчёт до 1e-4, детерминизм |
| `src/reinforce.rs` | Армирование здания: поля требуемой площади всех оболочек, добавка к фону, поперечная арматура, изополя DXF | Синтетическое здание: симметрия, фон, невозможный подбор |
| `src/building.rs` | Сетка здания целиком → плита (контур, отверстия), здание, сконденсированное на плиту, нагрузки, сваи КЭ 56 | Синтетика: плита с отверстием, колонны, перекрытие |
| `src/report.rs` | Отчёт HTML по варианту: данные, методики с пунктами норм, результаты, план, ведомость | В `service_run` |
| `src/service.rs`, `app/` | Временное окно Tauri 2 (как `topo_reconstruct_rs`, дизайн-код GeoBase): ввод, план (сваи, осадки, армирование), варианты, проверки варианта, проект, экспорт CSV/DXF | Playwright через `examples/ui_server.rs` |

Скорость (release, 4 ядра): пример по умолчанию (плита 24×18 м) ≈ 3 с; плита
48×36 м ≈ 48 с (доминирует полный подбор армирования вариантов фронта).
Тестов: 106 (`cargo test --release`).

## Принятые решения и допущения

- Расчёты сечений — перенос на Rust, а не вызов .NET (скорость, один exe);
  обновления автора — `upstream/opencs.lock`, `scripts/upstream_diff.sh`.
- Ошибка в CSfea `Shell4.BMatrixShear` (транспонированный Якобиан, на
  искажённой сетке прогиб −46 %) исправлена у нас; **автору не сообщать**
  (решение пользователя).
- СП 24: ν в ζ0, mν (табл. 7.18) — (ν1 + ν2)/2; отступ сваи от края ростверка
  в норме числом не задан — 0,5d + 0,1 м, параметр.
- СП 63: таблицы сверены (А400 по Изменению № 1: 340/340/390 МПа); Rsc А500 =
  400 МПа (кратковременное действие); деформации бетона — как в OpenCS.
- Трещины (п. 8.2.6): продолжительное — длительное сочетание, φ1 = 1,4, 0,3 мм;
  непродолжительное — полные сочетания с φ1 = 1,4, 0,4 мм (верхняя оценка
  acrc1 + acrc2 − acrc3). Подбор ПС2 — только где сетки ПС1 не проходят.
- Продавливание — пп. 8.1.46–8.1.47 без поперечной арматуры; у края — доля
  контура внутри плиты (упрощение двух вариантов контура).
- Загружения хранятся нормативными; признак «расчётные» — деление на γf.
- Вудбери: регуляризующие пружины плиты 1e-6 жёсткости сваи (берут ~1e-5
  нагрузки). Конденсированный суперэлемент для больших зданий неэффективен —
  для них полная модель «здание + плита» в K0.
- Сетка плиты в окне — квадратная по габариту (косые края ступенькой); сваи —
  в узлах сетки.

## План

1. ~~Femgeo: сетка здания → подбор~~ — сделано: `Service::run_mesh(input, &Mesh)`
   (плита, контур, h, низ плиты = z_mid − h/2, нагрузки, здание суперэлементом,
   КЭ 56 — существующие сваи, строка сравнения). Осталось: жёсткости КЭ 56 для
   сверки осадок с ЛИРА; для больших зданий — полная модель вместо суперэлемента
   (см. допущение про Вудбери).
2. **topo:** режим «Фундамент» — расчётная часть сделана (`13036c4`: `foundation_run`,
   см. DEV_STATE topo). Плита всегда на регулярной сетке Femgeo: узлы сопряжения и
   нагрузки — в ближайшие узлы (≤ полшага), части здания без связи с плитой
   исключаются с отчётом, поворотные стабилизаторы 1 кН·м/рад. Нет интерфейса
   (выбор плиты, виды загружений, параметры, показ вариантов и отчёта).
3. **ЖК Остров.** Сверка решателя с ЛИРА (`verify_mesh`, сваи-пружины КЭ 56, РСН
   пользователя): Rz по сваям 0,91–1,01 от ЛИРА (медиана 0,947, разброс ±1,8 %),
   ΣRz 538/564 МН, осадки 36–62/39–66 мм; дефицит — собственный вес (≈ 26 МН), см.
   DEV_STATE topo. Данные пользователя: d 0,88 м, L 19 м, Fd 7500 кН, s ≤ 15 см,
   плита B40; нагрузки модели расчётные, γf: СВ 1,1, полы 1,3, перегородки 1,2,
   полезная 1,2/1,3 (длительная доля 0,35), фасады 1,2, инж. 1,2, снег 1,4 (0,5),
   грунт 1,15; ветер в РСН не входит. Грунт — слои из расчёта сваи пользователя (dp 11,5 м → поверхность
   +0,65 в отметках модели; L 22,1 м по расчёту сваи, в имени файла — 19 м).
   Подбор по СП 24 (2026-11-02): 132 существующие сваи — Кисп грунт 2,33, материал
   1,66, продавливание 2,03, s 0,103 м; 203 сваи рядами — 2,25 / 1,60 / 1,31. Причина —
   краевая концентрация линейного взаимовлияния (п. 7.4.4): сваи у края (< 2 м) в
   среднем 6,6 МН, внутренние 2,6 МН, максимум 17,5 МН у входящих углов; в ЛИРА
   жёсткости КЭ 56 почти равны (±9 %), Rz ≤ 5,7 МН. Пользователь: жёсткости КЭ 56 — из
   3D-расчёта MIDAS с жёсткостью здания; линейная постановка под вопросом.
   Сделано: `pile_fu` — собственная податливость сваи f/(1 − N/Fu), Fu = Fd (решение
   пользователя), секущие жёсткости по определяющему ПС1. На Острове не сходится
   (Nmax 16,1 МН у 132 свай, 10,7 МН у 203): краевую концентрацию дают члены
   взаимовлияния, а не собственная податливость. Варианты: пластический предел Fu
   (активное множество), жёсткости по осадке поля (как MIDAS/ЛИРА), нелинейность
   во взаимовлиянии — решение за пользователем.
4. Убрать `app/`, `examples/ui_server.rs`, workflow «App» — после п. 2.
5. Позже: особые сочетания; моменты и поперечная арматура в продавливании;
   трещины и поперечная сила свай; η; γb1; ускорение подбора армирования
   больших плит; отчёт DOCX и изополя; грунт по кригингу (в geobase не
   сохраняется); 3D-грунт (Code_Aster).

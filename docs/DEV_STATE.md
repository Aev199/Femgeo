# Состояние разработки

Обновлено: 2026-11-03. Постановка — `docs/SPEC.md`. Ветка работы — `stage1-sp63-plates`
(в `main` только постановка). Историю решений смотреть в `git log`.

## Схема

topo_reconstruct_rs (ЛИРА → восстановление и доводка геометрии → сетка Gmsh → нагрузки;
окно, режим «Фундамент») → `femgeo::building::split` (плита, здание суперэлементом, сваи
КЭ 56, вертикальные конструкции) → `optimize::Problem` (подбор свай, этап 1) →
`Service::design_underground` (подземная часть, этап 2) → окно topo, отчёт, DXF.
Femgeo — библиотека (git-зависимость topo); своё окно `app/` временное.

## Методика (решения пользователя и допущения)

**Нагрузки и сочетания.** СП 20 п. 6.4; загружения хранятся нормативными, признак
«расчётные» — деление на γf. Собственный вес — по γ материалов (в ЛИРА часто в монтажных
стадиях, topo их не переносит), отдельным загружением.

**Жёсткость свай** (решение 2026-11-02): одинаковая k = N / (n·s), s — осадка условного
фундамента (контур плиты + L·tg(φmt/4), Буссинеск по контуру, СП 22 п. 5.6.31, β 0,8,
Ee = 5E, граница σzp = 0,5σzg; без подземных вод; пункты — по памяти), N — длительное ПС2.
Если в сочетании N > Fu (= Fd) — сваи держат Fu, избыток перераспределяется; допустимо
≤ 10 % свай на пределе. Осадка от числа свай не зависит (принято). Режим СП 24 п. 7.4
(линейное взаимовлияние) оставлен — в большом поле даёт завышенную краевую концентрацию.

**Ограничения.** s ≤ задано, Δs/L ≤ задано (Остров — 0,003) между соседними
вертикальными конструкциями (пары узлов разных конструкций до 12 м — допущение);
Fd, материал сваи, армирование плиты ПС1/ПС2 (трещины п. 8.2.6: φ1 1,4; 0,3/0,4 мм).

**Продавливание.**
- Сваи, колонны — СП 63 пп. 8.1.46–8.1.47; колонны с Mx, My от здания (M/Mb ≤ F/(2Fb)).
- Торцы стен — СП 430.1325800.2018 п. 6.3.8, рис. 6.1: контур 3(t + h0), F —
  равнодействующая поперечных сил плиты по контуру, M — ½ разности изгибающих моментов по
  обе стороны стены; у края — контур 1′ (от края до a1 за торцом), не для стены вдоль края.
- Углы стен — рис. 6.2: наружный 2(a1 + a2) и внутренний (диагональ) контуры, только N.
- Поперечная арматура — пп. 8.1.48–8.1.50: при Fb < F ≤ 2Fb, масса в кг/м³ (зона ×1,5 —
  допущение; Rsw 300 МПа — по памяти, сверить).

**Расстановка.** Плита — регулярная сетка Femgeo (узлы сопряжения и нагрузки — в
ближайшие узлы, ≤ полшага); приоритет узлов у колонн, торцов, углов и под стенами;
перенос свай к определяющей по продавливанию конструкции.

**Подземная часть.** Модель этапа 1 даёт перемещения узлов сопряжения (билинейно по
сетке), здание решается на своих узлах (штрафы uz, θx, θy; предел Fu не учитывается);
подбор `reinforce::design` для пластин ниже поверхности грунта; бетон, арматура,
защитный слой — как у плиты (допущение); у особых точек — осреднение в радиусе h.

**Сечения.** Перенос OpenCS по алгоритму источника; отступления: исправлена ошибка CSfea
`Shell4.BMatrixShear`; `required_uls` при растяжении с малым эксцентриситетом сравнивает с
двусторонним армированием (`55085a8`, отпечаток обновлён). Автору OpenCS не сообщать.

**Прочее.** Части здания без связи с плитой исключаются с отчётом о нагрузке; поворотные
стабилизаторы узлов здания 1 кН·м/рад. СП 24: отступ сваи от края 0,5d + 0,1 м (параметр).

## ЖК Остров (проверочная модель, не коммитить)

Данные пользователя: сваи d 0,88 м, L 22,1 м (по расчёту сваи; в имени файла — 19 м),
Fd 7500 кН, бетон В30, 10Ø20 А500 (армирование — допущение); плита B40, h 1,4 м, низ
−10,85; s ≤ 0,15 м, Δs/L ≤ 0,003; грунт — 6 слоёв (E, ν, γ, φ) из расчёта сваи,
поверхность +0,65 в отметках модели. Нагрузки модели расчётные, γf: полы 1,3,
перегородки 1,2, полезная 1,2/1,3 (ψ 0,35), фасады 1,2, инж. 1,2 (длит.), снег 1,4
(0,5), грунт 1,15, СВ 1,1; ветер в РСН не входит.

- Сверка решателя с ЛИРА (`foundation_verify`, сваи КЭ 56, РСН1/РСН2): Rz по сваям
  0,91–1,01 (медиана 0,947, ±1,8 %), ΣRz 538/564 МН, осадки 36–62/39–66 мм. Дефицит
  ≈ 26 МН — собственный вес (потери восстановления или иной вес в ЛИРА) — не выяснен.
- Подбор (свободно): фронт 132 → 73 сваи, все допустимы; продавливание конструкциями
  1,2–1,4 (существующие — 1,99) с поперечной арматурой 0,3–0,7 кг/м³; 89 свай —
  16,4 кг/м³, Кисп грунт 0,84. Расчёт ≈ 6 мин, открытие модели ≈ 3 мин.
- Подземная часть (89 свай): 8515 элементов, ≈ 1 мин; 11,2 т теоретически, 9,0 кг/м³;
  максимум 50 см²/м (осреднённый), 150 см²/м (сырой; ЛИРА — до 96–171); бетонная
  полоса не проходит в 5 элементах.

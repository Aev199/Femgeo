# Femgeo

Проверочный инструмент для каркасных зданий на свайных фундаментах:

- **подбор расстановки свай** под сплошной плитой: фронт вариантов «число
  свай — расход армирования плиты, кг/м³» при ограничениях по несущей
  способности свай по грунту и материалу, допустимому контуру, требованиям
  СП 24 и осадкам;
- **подбор армирования** всего здания по СП 63 (поля требуемой площади) по
  расчёту на грунтовом основании.

Исходные данные: модель ЛИРА (через `topo_reconstruct_rs`), грунты и скважины
из geobase. Расчёты сечений по СП 63 — перенос из
[OpenCS / CScore](https://github.com/rumata-ap/OpenCS).

Статус: этап 1 — подбор армирования плит по Капра–Мори (ПС1, ПС2) готов, см.
`docs/DEV_STATE.md`. Постановка — `docs/SPEC.md`.

```sh
cargo test --offline
```
